# Unified UUIDv7 Identifiers

## Context and Problem Statement
Який тип даних використовувати для первинних (PK) та зовнішніх (FK) ключів у всіх сутностях CRM-системи?

## Decision Outcome
Обрано: **UUIDv7**.

### Positive Consequences
* Забезпечує глобальну унікальність ідентифікаторів при розподіленій архітектурі.
* На відміну від UUIDv4, UUIDv7 сортується за часом створення, що значно покращує продуктивність індексів.
